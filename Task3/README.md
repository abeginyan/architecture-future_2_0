## Кратко

- **Выводим:** MS SQL Server 2008 (DWH), логику в хранимых процедурах, Apache Camel ESB, Power BI поверх DWH, PowerBuilder. Аналитическая часть DWH уходит в чтение и архив, а запись клиник в старый контур закрывается только после проверенного переноса клинических операций.
- **Внедряем:** облако, Kubernetes, Kafka с реестром схем, паттерны надёжности интеграций, PostgreSQL, единый вход (Keycloak), шифрование, мониторинг, DDD и событийную интеграцию.
- **Пилотируем:** Kafka Streams (проверки и преобразования вместо ESB), Data Mesh и data products, озеро (Iceberg), ClickHouse, dbt, каталог данных, BI на семантическом слое.
- **Сохраняем:** Go, Java и Python в финтех- и ИИ-сервисах.
- **Роадмап:** этапы 0–2, 2–6, 6–9, 9–12 месяцев (как в Задании 1). К месяцу 6 появляются первые отчёты за минуты, к 9 финтех и ИИ развиваются без правок в DWH, к 12 работает портал, подключён первый партнёр и пройдены учения по восстановлению.

## Как пересобрать картинки

```bash
python3 build_radar.py      # tech_radar.png и tech_radar.md
python3 build_roadmap.py    # roadmap.png
```

Нужен Python 3 с библиотекой matplotlib.
