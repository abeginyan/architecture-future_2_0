## Кратко

**Домены:** 1. Клиники · 2. ИИ-сервисы · 3. Финтех / Банк · 4. Головной офис · 5. Партнёры (шаблон для фармы и электроники) · 6. Интеграция и безопасность · 7. Платформа данных (витрина).

**Сценарии на DFD:**
- **A (красный)** — ИИ анализирует медицинские данные: данные ходят только между клиникой и ИИ через шлюз, в платформу данных не попадают.
- **B (синий)** — подключение нового финтех-сервиса и оплата лечения: изменения только в домене финтеха и регистрация контракта.
- **C (зелёный)** — быстрая отчётность: события доменов, витрины, самообслуживание с проверкой ролей.
- **D (оранжевый)** — подключение партнёров по шаблону.

**Ключевая идея:** ни один новый продукт, партнёр или отчёт не требует новой логики в DWH. Подробности в [argumentation.md](argumentation.md).

java -DPLANTUML_LIMIT_SIZE=16384 -jar plantuml.jar -tpng DFD.puml
